# «Мой гараж»: инструкции для ИИ-агентов

Перед правками в этом репозитории прочитай [правила разработки](src/rules/rules.md). Они применяются ко всему проекту.

«Мой гараж» — клиентское приложение на Vue 3, Pinia, TypeScript и Vite для учёта трат, заправок и обслуживания автомобилей. Серверной части нет: интерфейс получает профили и записи из Pinia, а стор сохраняет их локально в браузере.

Следуй явным инструкциям пользователя. Не запускай приложение, сборку, тесты, линтеры или форматтеры; работай через чтение, правки и статический анализ. Не предлагай проверки и не запрашивай разрешение на них. Отвечай по-русски; кратко опиши результат, приложи изменённый код или diff и объясни ключевые решения.
